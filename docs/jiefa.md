# 洁珐详细介绍

洁珐是 NAI 中文作者助手内置的**本地语义推荐功能**。它不是一个替用户写完整提示词的聊天机器人，也不负责自动生成图片；它更像是一位随时可以询问的 Tag 助手：你可以先用中文描述想要的画面，再从推荐结果中挑选适合的 NovelAI Tag。

## 一句话理解

普通搜索解决“我知道这个 Tag 大概叫什么”；洁珐解决“我知道自己想表达什么，但不确定应该使用哪些 Tag”。

例如：

```text
输入：黄昏城市里的火焰少女
可能关注：夕阳、城市、火焰、少女、黄昏光线等相关概念
```

洁珐会尝试从描述中识别多个概念，并分别寻找相关 Tag。最终使用哪些 Tag，仍由用户自己判断和导入。

## 洁珐能做什么

### 1. 用自然语言寻找 Tag

不需要先记住标准英文写法。你可以输入：

- `黄昏城市里的火焰少女`
- `穿着宽大白衬衫的女孩`
- `雨夜里有霓虹灯的街道`
- `蓝色眼睛，长发，微笑`

对于较短的英文或中文词，软件会优先保留普通查词结果；对于较长的中文短语或句子，洁珐会尝试提取其中的多个语义片段。

### 2. 给出可选择的推荐，而不是直接改写提示词

洁珐的结果会显示在推荐栏中。你可以：

1. 查看推荐 Tag 及其中文说明。
2. 按需勾选一个或多个结果。
3. 查看关联推荐。
4. 点击“导入已选”或单独点击某一项。
5. 继续使用权重、排序和文本编辑工具整理结果。

洁珐不会在没有确认的情况下把结果直接写入提示词框，也不会替你删除已有 Tag。这样可以避免一次模糊理解覆盖正在编辑的内容。

### 3. 与普通搜索、关联推荐配合使用

推荐栏中的几类结果各有用途：

- **普通匹配**：适合查找明确的英文 Tag、中文名称、别名、角色和画师。
- **语义推荐**：由洁珐根据短语或句子含义提供候选。
- **关联推荐**：根据已经选择的 Tag，补充常见的共现 Tag 或画师擅长 Tag。

实际使用时，可以先用普通搜索确定核心 Tag，再让洁珐补充氛围、动作、场景或视觉特征，最后通过关联推荐完善细节。

## 推荐的使用流程

### 适合新手的流程

1. 打开一个正面或负面提示词框。
2. 输入一段自然描述，不必一次写得很长。
3. 等待推荐栏更新。
4. 先阅读中文说明，再选择真正符合画面意图的 Tag。
5. 导入后检查权重、重复项和正负面位置。
6. 再补充角色、服装、构图等明确 Tag。

建议先从一句短描述开始，例如“雨中的红伞女孩”，然后逐步补充，不要把整段小说直接粘贴进去。

### 适合熟悉 Tag 的流程

可以把洁珐当作查漏工具：先手动写出核心 Tag，再输入一段更具体的视觉描述，查看是否有遗漏的场景、光线、材质或动作候选。确认后只导入需要的部分，避免让推荐结果替代自己的构思。

## 它与 AI 辅助撰写有什么区别

软件中“洁珐”和“AI Tag 撰写”是两个不同功能：

| 功能 | 洁珐 | AI Tag 撰写 |
| --- | --- | --- |
| 主要用途 | 从语义描述中查找和推荐 Tag | 根据用户要求组织较完整的中文描述与 NovelAI Prompt |
| 是否默认联网 | 不需要 | 只有用户配置并主动使用 API 时才联网 |
| 是否需要 API Key | 不需要 | 需要用户自行配置兼容接口 |
| 输出方式 | 推荐栏中的可选 Tag | AI 面板中的文本结果，可复制或新建画作导入 |
| 用户控制 | 用户逐项选择和导入 | 用户检查生成内容后再复制或导入 |

如果只是想查找几个 Tag，优先使用普通搜索或洁珐；如果想从较完整的创作要求整理出提示词草稿，再考虑使用 AI 辅助撰写。

## 隐私与联网说明

洁珐使用随软件提供的本地语义模型和本地标签数据，核心语义查询不需要把提示词发送到网络服务，也不需要填写 API Key。普通 Tag 检索、角色检索、关联推荐和洁珐推荐都以本地资源为主。

需要特别区分的是：**AI 辅助撰写不是洁珐**。当用户在设置中填写 OpenAI-compatible API 信息，并主动点击 AI 生成按钮时，软件才会向用户配置的服务发送本次请求所需内容。请根据所选服务的隐私政策判断是否适合输入私人创作内容。

洁珐本地运行并不意味着所有软件功能都离线：用户主动使用 AI 辅助撰写、打开 NovelAI 官网或进行其他外部联动时，仍可能产生网络访问。

## 模型加载与性能

为了避免首次打开软件时卡住输入，洁珐模型不会在界面启动瞬间强制阻塞编辑器。模型准备完成后，软件会在用户短暂空闲时按需加载；模型准备期间仍可进行普通 Tag 输入和编辑。

程序会优先使用设备可用的图形加速能力；不适用时回退到兼容性更好的本地运行方式。输入流畅度优先于推荐速度：连续输入时，旧的语义查询会被取消或让位给最新内容，避免过时结果反复刷新推荐栏。

窗口最小化或进入后台后，洁珐会降低或暂停高耗资源工作；恢复窗口时再按需继续。若设备内存较紧张，建议关闭“模型就绪后自动开启洁珐”，需要时再手动开启。

## 推荐结果为什么不一定准确

洁珐提供的是候选，不是最终判断。以下情况都可能导致结果不完全符合预期：

- 一个中文词在不同语境下对应多个英文 Tag。
- NovelAI Tag 的表达方式与自然语言不完全一致。
- 描述包含抽象情绪、复杂动作或多个互相影响的条件。
- 冷门概念在标签库中的引用较少。
- 同一个画面需要多个 Tag 共同表达，单个推荐项看起来可能不完整。

使用前请检查 Tag 的英文写法、中文说明、所属类别和是否适合放在正面或负面提示词中。对关键角色、作品名、画师名和特殊风格，建议同时使用普通搜索、角色库或 Wiki 说明进行确认。

## 常见问题

### 为什么开启洁珐后没有立即出现结果？

首次开启时需要准备本地模型。请等待模型状态显示为已就绪，再停止输入片刻。输入法仍在组词时，软件会优先处理文字输入，不会频繁启动语义查询。

### 为什么普通搜索有结果，但洁珐没有结果？

普通搜索按文字、别名和规范化名称匹配；洁珐按语义相似度筛选候选。两者的判断方式不同。已知确切名称时，普通搜索通常更快、更可靠。

### 能否完全关闭洁珐？

可以。点击顶部的洁珐按钮即可关闭；也可以在设置中关闭“语义模型就绪后自动开启洁珐”。关闭洁珐不会影响普通 Tag 检索、角色库、权重工具和文本编辑。

### 洁珐会自动生成图片或消耗 NovelAI 点数吗？

不会。洁珐只提供本地 Tag 推荐，不会自动登录 NovelAI、填写官网、点击生成或消耗点数。

## 使用建议

把洁珐当作“语义查词和灵感补全工具”，而不是自动提示词生成器，通常能得到更稳定的结果：

- 核心角色、作品和主体由自己确认。
- 抽象氛围、场景细节和视觉特征交给洁珐辅助查找。
- 每次只导入真正需要的推荐项。
- 导入后检查重复、权重、正负面位置和 Tag 顺序。
- 对重要提示词保留自己的预设，避免完全依赖一次推荐结果。
